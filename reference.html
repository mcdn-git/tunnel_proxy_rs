7. Router 编排配置

# run -C router.yaml
chains:                # 候选代理链
  - name: c1
    nodes:
      - name: hop1
        proto: socks5
        addr: 1.2.3.4:1080
        user: u
        pass: p
    retry: 2
strategy: RoundRobin   # RoundRobin / Random / Weighted / Hash
bypass:                # 旁路直连
  - 127.0.0.0/8
  - "*.internal"
reverse: false
limit:                 # 限流
  max_connections: 1000
  token: 1000000
  hourly_bytes: 50000000
services:              # 单进程多服务
  - name: socks
    addr: 0.0.0.0:1080
    proto: socks5
webhook:               # observer 事件回调
  url: http://127.0.0.1:9000/hook
  events: [connect, close]
  timeout_secs: 5

/metrics/prometheusGET始终 Prometheus 文本
/statusGET完整状态（指标 + 链信息 + 策略）
